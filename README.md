# M.J. JARVIS V1.3.2

Android starter for Vivo V80 (Android 15). Includes a Kotlin app, SDK 35, editable/savable/resettable English greeting, tap-to-talk speech recognition and text-to-speech, WhatsApp and YouTube launch, Wi-Fi/Bluetooth/alarm settings, and dialer launch for a spoken number.

APK build: GitHub Actions runs on push to main. Open Actions, choose Android APK Build, and download the MJ-JARVIS-V1.3.2-debug artifact after success.

Not implemented yet: always-on wake word, background listening, scheduled WhatsApp sending, direct calling, and complete Gujarati/Hindi/English command handling. Call opens the dialer only; sensitive actions remain user-controlled.
